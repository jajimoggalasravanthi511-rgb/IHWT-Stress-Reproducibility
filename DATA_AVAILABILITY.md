# Data Availability

The repository does not invent or redistribute the manuscript's custom 50-participant physiological recordings. Independent reproduction of the exact custom-cohort numbers requires the real de-identified ECG, GSR, and PPG recordings, pseudonymous subject identifiers, labels, acquisition metadata, and the ethics/consent basis that permits sharing.

If participant consent and institutional approval permit public release, archive the raw/processed dataset in a DOI-assigning repository and add the issued DOI here and in the final paper. If raw human-subject data cannot legally or ethically be made public, state the precise restriction instead of claiming public availability, and provide the strongest permissible derived data plus an access procedure.

For independent algorithm verification, the repository includes `prepare_wesad.py`, which converts the publicly available WESAD benchmark into the same manifest interface. WESAD external-validation results must be reported separately from the custom cohort.
